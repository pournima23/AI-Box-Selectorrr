# What I Learned

This assignment gave me hands-on experience with Django and helped me understand how a web application is built from scratch. Before this project, I only knew the basics, but while working on it I learned how different parts of Django connect and work together.

I learned how to create models, views, URLs, templates, and APIs. I also understood how to design the database for products, boxes, orders, and order items. Working with Django migrations and the admin panel helped me understand how data is stored and managed.

During the project, I faced several problems like migration errors, URL issues, and 404 errors. Instead of giving up, I tried to understand the errors and fix them one by one. This improved my debugging skills and made me more confident.

I also learned how to use Git and GitHub properly. I understood how to commit changes, push my project to GitHub, and maintain project documentation with files like README, AI Usage, Test Cases, and Test Output.

The biggest lesson I learned is that building a project step by step makes the process much easier. Whenever I got stuck, I focused on solving one problem at a time, and that helped me complete the project successfully.

Overall, this assignment improved my Django knowledge, problem-solving skills, and confidence in building backend applications. It was a great learning experience, and I now feel more comfortable working on similar projects in the future.

# AI Usage Report

## AI Tool Used

- ChatGPT (OpenAI)

---

## How AI Was Used

I used ChatGPT as a learning and troubleshooting assistant while developing this project. Whenever I encountered an issue or was unsure about the next step, I asked questions to understand the concept or resolve the problem.

The AI was mainly used to clarify Django concepts, fix development errors, understand Git commands, and improve the overall development workflow. Instead of relying on AI to generate the complete project, I implemented each feature step by step and verified the output after every change.

---

## My Contribution

I developed the project by setting up the Django environment, creating the project structure, implementing models, configuring URLs and views, designing the user interface, testing the recommendation functionality, resolving errors, and uploading the final project to GitHub.

AI suggestions were used only for guidance and problem-solving. Every solution was reviewed, understood, tested, and modified wherever required before being included in the project.

---

## Reflection

Using AI made the development process smoother by helping me understand concepts and resolve technical issues more efficiently. It acted as a learning companion throughout the project, while the implementation, testing, debugging, and final verification were completed by me.
